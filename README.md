# HerdCare — Hybrid Animal Health Monitoring System

A responsive 3D-inspired dashboard prototype for a college project. It includes animal photos, a veterinarian profile, farm banner, dashboard cards, sample sensor readings, an SVG trend chart, alerts, species cards, animal details, filters, and a form for adding local sample records.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet access is needed to load the remote animal/farm photos.

## Important
This is a front-end demo. The values are sample data, not live sensor readings or veterinary diagnosis. Sensor hardware, backend/API, persistent database, secure accounts and actual notifications are not connected. Real thresholds and sensor selection must be reviewed with a qualified veterinarian.

## Suggested stack for the next stage
HTML, CSS, JavaScript; ESP32 or a suitable IoT controller; validated animal-safe sensors; backend API; cloud database; and a veterinarian-reviewed alert workflow.
